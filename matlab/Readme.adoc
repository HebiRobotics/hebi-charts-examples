= HEBI Charts - MATLAB

This directory contains the HEBI Charts examples for link:https://mathworks.com/products/matlab.html[MATLAB]. For more information about the library, check the main link:../Readme.adoc[Readme].

== Installation

HEBI Charts provides a zero-configuration setup via link:./hebi_charts/+hebi_charts/private/locate_binary.m[locate_binary.m], which automatically fetches platform-specific binaries and manages them in a shared local system cache upon running examples. A dedicated native toolbox distribution is currently in development.

* Simply run link:./startup.m[startup.m] or add the `hebi_charts` directory to your MATLAB path.

The library utilizes a self-contained MEX gateway. Pre-compiled MEX binaries for link:./hebi_charts/+hebi_charts/private/hebi_charts_native.cpp[hebi_charts_native.cpp] are included for all major platforms and require MATLAB 2018b or later.
