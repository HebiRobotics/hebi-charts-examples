= HEBI Charts - C++

This directory contains the HEBI Charts examples for link:https://www.w3schools.com/cpp/[C++]. For more information about the library, check the main link:../Readme.adoc[Readme].

== Installation

HEBI Charts features zero-configuration installation implemented inside link:hebi_charts/hebi_charts.cmake[hebi_charts.cmake]. Configuring a target with the provided CMake macro automatically fetches the correct platform-specific binaries and stores them in a shared local system cache.

[source,cmake]
----
# Import CMake macros
include(hebi_charts/hebi_charts.cmake)

# Add hebi_charts dependencies to your target
add_executable(main src/main.cpp)
target_add_hebi_charts(main)
----

The `target_add_hebi_charts` macro configures compiler include paths and automatically copies the required dynamic library components into your target's build output directory, ensuring they are resolved properly at runtime.
