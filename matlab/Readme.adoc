= HEBI Charts - MATLAB

This directory contains the HEBI Charts examples for link:https://mathworks.com/products/matlab.html[MATLAB]. For more information about the library, check the main link:../Readme.adoc[Readme].

== Installation

HEBI Charts features zero-configuration installation implemented inside link:./hebi_charts/+hebi_charts/private/locate_binary.m[locate_binary.m]. Running any of the examples automatically fetches the correct platform-specific binaries and stores them in a shared system cache. A dedicated native toolbox distribution is currently in development.

* Simply run link:./startup.m[startup.m] or manually add `hebi_charts` to the path

The library uses a zero-dependency dynamically compiled MEX gateway. Pre-compiled MEX files for link:./hebi_charts/+hebi_charts/private/hebi_charts_native.cpp[hebi_charts_native.cpp] are provided for all platforms and should be compatible with `MATLAB 2018b` or later versions.
