= HEBI Charts - Python

This directory contains the HEBI Charts examples for link:https://www.python.org/[Python]. For more information about the library, check the main link:../Readme.adoc[Readme].

== Installation

You can download the latest pip package using

* `pip install hebi-charts` (latest stable build)
* `pip install -i https://test.pypi.org/simple/ hebi-charts` (latest snapshot build)

Alternatively, you can copy the link:./hebi_charts/hebi_charts.py[hebi_charts.py] file into your project, and it will automatically fetch the matching platform-specific binaries and manage them in a shared local system cache after the first call.

While no external dependencies are required for base functionality, https://pypi.org/project/numpy/[NumPy] is needed for bulk array methods.
